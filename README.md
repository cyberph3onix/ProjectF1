\# 🏎️ ProjectF1 — F1 Race Outcome Prediction



ProjectF1 is a data-driven Formula 1 race prediction project built using historical race and qualifying data.  

The goal is to predict race outcomes \*\*before the race begins\*\* using pre-race features.



---



\## 📊 Data Source

\- Formula 1 session data collected using \*\*FastF1\*\*

\- Historical race data from \*\*2019–2024\*\*

\- Processed into structured CSV datasets per Grand Prix



---



\## ⚙️ Tech Stack

\- Python

\- Pandas

\- NumPy

\- Scikit-learn

\- FastF1

\- Jupyter Notebook



---



\## 🧠 Approach

1\. Collected historical qualifying and race data

2\. Engineered pre-race features

3\. Trained a machine learning model to predict race outcomes

4\. Evaluated model performance using appropriate regression metrics
